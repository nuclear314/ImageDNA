# Provides the `gi` module (GObject Introspection bindings) that pywebview's
# GTK backend and linux/main.py's fatal-error dialog both import. Building
# this from source requires libgirepository-2.0-dev (current PyGObject
# >=3.51.0 no longer builds against the older libgirepository1.0-dev - see
# .github/workflows/build.yml's runs-on comment) + gobject-introspection +
# pkg-config present on the BUILD machine (see linux/build.sh's apt package
# list / .github/workflows/build.yml) — not required on the end user's
# machine, since the built app only needs the runtime GTK/WebKit2GTK libs.
# Since PyGObject is bundled by PyInstaller (unlike libglib/libgtk/
# libwebkit2gtk themselves, which imagedna.spec deliberately excludes as
# system prerequisites — see its comment), an unpinned install here silently
# ships whatever PyGObject happened to resolve on the BUILD machine. On any
# end-user system with GLib >=2.88 (e.g. current Arch/Artix/Fedora Rawhide)
# this crashes at gi.repository.Gtk import time with "AssertionError:
# unix_signal_add_full was set deprecated but wasn't added to __all__" —
# confirmed still present in PyGObject 3.57.0 (the latest tagged upstream as
# of this writing), so no version pin here fixes it; see build.sh's patch
# step immediately after this file is installed, which fixes the actual
# broken gi/overrides/GLib.py logic directly
# (https://gitlab.gnome.org/GNOME/pygobject/-/work_items/757).
